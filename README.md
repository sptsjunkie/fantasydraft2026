# Fantasy Baseball Draft Tool 2026

A standalone React app for tracking your fantasy baseball snake draft in real time. Built with Vite.

## Local Development

```bash
npm install
npm run dev
```

Open [http://localhost:5173/fantasydraft2026/](http://localhost:5173/fantasydraft2026/) in your browser.

## Build

```bash
npm run build
```

The production build is output to the `dist/` directory.

## Deploy to GitHub Pages

```bash
npm run deploy
```

This runs `npm run build` automatically (via `predeploy`), then publishes the `dist/` folder to the `gh-pages` branch.

Once deployed, the app is available at:

```
https://<your-username>.github.io/fantasydraft2026/
```
