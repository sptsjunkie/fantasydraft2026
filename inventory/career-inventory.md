# Career Inventory

> **This file is the single source of truth for every claim on every resume.**
> If an accomplishment, metric, title, date, or skill is not written here, it cannot
> appear on a tailored resume. Add it here first, then tailor.

## How to use this file

- One `## Role` section per position, most recent first.
- Every accomplishment gets a **unique, permanent ID**: `<COMPANY-PREFIX>-<NN>`
  (e.g., `PS-01`, `MCK-03`, `SMASH-02`). Never renumber or reuse an ID — downstream
  job folders reference them. Retire an accomplishment by marking it `RETIRED`, not deleting it.
- Write accomplishments in full, plain sentences. Resume phrasing happens later, per job.
- **Metric confidence** must be one of:
  - **Verified** — documented (report, dashboard, review, press release); you could show proof.
  - **Estimated** — your reasoned calculation from real inputs; defensible in an interview.
  - **Directional** — real effect, but the number is a rough order of magnitude. Use cautiously.
- Separate **what you personally did** from what the team did. The fact-checker will hold
  resume verbs ("led", "built", "owned") to this distinction.
